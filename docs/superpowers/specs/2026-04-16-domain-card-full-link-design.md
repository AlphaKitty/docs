# 领域卡片完整联动设计

**目标**

将技能页顶部领域卡片从展示型入口升级为完整联动入口，支持真实查看详情、真实编辑、真实删除。

**范围**

- 仅修改 `expert-link-frontend`
- 后端继续复用现有领域 CRUD 接口
- 保留 `SkillList.vue` 当前布局，领域卡片仍作为入口区

**设计**

1. 入口页
   - `SkillList.vue` 中领域卡片继续保留
   - `查看详情` 跳转到独立领域详情页
   - `编辑` 跳转到独立领域编辑页
   - `删除` 在当前页直接调用真实删除接口，成功后刷新卡片

2. 路由
   - 新增 `/domains/:id`
   - 新增 `/domains/:id/edit`

3. 页面
   - `DomainDetail.vue`
     - 展示领域基础信息
     - 展示父级/层级信息
     - 展示专家数、项目数
     - 展示该领域下技能列表
   - `DomainEdit.vue`
     - 编辑基础字段
     - 至少支持 `name / description / parentId / isActive`
     - 使用真实领域列表作为父级选择器

4. 验证
   - 领域卡片可跳领域详情页
   - 领域卡片可跳领域编辑页
   - 领域编辑后详情页可见变更
   - 领域删除成功后卡片消失
