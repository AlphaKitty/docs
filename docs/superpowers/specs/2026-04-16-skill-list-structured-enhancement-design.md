# 技能列表结构化增强设计

**目标**

在不改动技能列表主布局的前提下，让 `SkillList` 展示真实结构化字段，并补充轻量交互入口。

**范围**

- 仅修改 `expert-link-frontend`
- 保留现有分页、顶部领域卡片、表格整体布局
- 不扩展为抽屉页或完整编辑系统

**设计**

1. 表格展示增强
   - 新增 `标签` 列：显示前 2 到 3 个标签，超出显示 `+N`
   - 新增 `相关技能` 列：显示数量，并支持悬浮提示技能名
   - 新增 `文档` 列：显示“有文档/无文档”状态

2. 轻交互增强
   - 操作列新增 `文档` 按钮
   - 点击后使用轻量弹窗或消息框展示文档内容
   - 无文档时显示“暂无文档”

3. 数据映射
   - 继续沿用当前 `SkillList.vue` 的真实接口加载逻辑
   - 在列表适配层补充：
     - `tags`
     - `relatedSkills`
     - `documentation`
   - 保持旧数据兼容：缺失结构化字段时按空数组或空文档处理

**验证**

- 列表可显示真实标签
- 列表可显示真实相关技能数量
- 列表可显示文档状态
- 点击文档按钮可查看真实文档内容
- 不引入已编辑文件的新诊断错误
